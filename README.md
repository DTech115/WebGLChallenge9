# WEBGLWeekly9

## Reflection
1. Which model was easiest to integrate and why?  
The market stand, as it just needed to be scaled a little & was easy to place.
2. What challenges did you encounter when importing models?  
Mostly naming inconsistencies & finding free models from other sites.
3. How did collision detection improve the realism of your scene?  
It made models not clip through walls, items, etc. like in real life.
4. If you had another hour, what feature would you add next?  
I'd make the waffle collectable & do something fun after.
5. What is the difference between a decorative model and an interactive model?  
Decorative models simply sit there for decoration while interactive ones have some sort of interaction with you or the scene.
